# Game design — Cyber Protocol

## Pillars

1. Real code: Python puzzles execute in CPython, not a text-matching mock.
2. Fictional ethical investigations: all targets and evidence are simulated.
3. Mobile-first usability: split case/terminal and editor interface with shortcut keys.
4. Expandable chapters: story and mission content are data-driven.

## Chapter 1 — Signal in the Noise

The player joins the fictional Helix Dynamics security operations team as a junior analyst. Mentor Mara assigns an audit of a corrupted access log. The first objective is to read the virtual file and count lines containing `ERROR`.

Expected result: `2`.

## Progression

The first mission defines a reward of 100 XP and 50 credits. The UI currently displays a prototype status only; persistent XP, inventory, and branching dialogue will be implemented in subsequent milestones.
